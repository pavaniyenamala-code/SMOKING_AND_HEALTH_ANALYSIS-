# Smoking and Health Analysis

## Project Overview
This project analyzes patient health data to understand smoking patterns, patient demographics, and their relationship with different health conditions using Power BI.

## Objectives
1. Analyze patient health KPIs.
2. Create Age Groups and Blood Pressure Risk Categories using DAX.
3. Analyze smoking patterns and health conditions.
4. Study patient demographics and health outcomes.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Analysis
- Total Patients and Current Smokers
- Cholesterol by Smoking Status
- Organ-wise Health Conditions
- Blood Pressure Risk Analysis
- Patient Demographics by Age Group

## Project Outcome
Created an interactive three-page Power BI dashboard to explore patient health indicators, smoking patterns, and demographic insights.
